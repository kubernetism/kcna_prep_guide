Cloud Native vs Cloud Service Providers
A Cloud Service Provider (CSP):

A collection of cloud services
Strong application integration and synergies between services
Utilizing metered billing
Under a single unified API
Cloud-Native is a workload, application, or system, that is designed to run on cloud services, and “takes advantage of cloud offerings”

Cloud-Native workloads cannot take advantage of all or full the advantage of CSPs because CSPs intentionally have proprietary technology to encourage you to use their managed services that have exclusive integrations with other services.
