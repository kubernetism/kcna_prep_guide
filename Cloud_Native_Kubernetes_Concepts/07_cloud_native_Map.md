Cloud Native Trail Map
The Cloud Native Trail Map is a recommended path to adopting Cloud-Native architecture

Containerization
Continuous Integration and Deployment (CI/CD)
Orchestration and Application Definition
Observability and Analysis
Service Proxy, Discovery and Mesh
Networking Policy, and Security
Distributed Databases and Storage
Streaming and Messaging
Container Registry and Runtime
Software Distribution
A. Training and Certification
B. Consulting Help
C. Join CNCF End User Community
The path order will vary based on your use-case. All parts of the path will be trekked during adoption.
